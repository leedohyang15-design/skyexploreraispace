# SkyExplorer 카메라 명령어 총정리 (어디서 되고/안 되고 + 상황별 사용법)

> 핵심 원리 하나만 기억: **카메라 명령은 "지금 어느 프레임(뷰)에 있느냐"에 따라 되고 안 됨이 갈린다.**
> 프레임은 3종: **① 지상 Sky View**(reset 기본, 관측지 밤하늘) / **② 행성·우주 프레임**(FadeTo/GoTo/ConnectTo 후) / **③ 성운·성단 LOS 프레임**(딥스카이 진입 후).

---

## 🧭 한눈 매트릭스 (프레임 × 명령)

| 명령어 | ① 지상 Sky View | ② 행성/우주 | ③ 성운/성단 | 한 줄 용도 |
|---|:---:|:---:|:---:|---|
| `setOrientationH(H, Anim)` | ✅ 좌우조준 | △ | △ | 지상서 천체 방위 조준 (H=180−방위) |
| `setTargetHeight(t, Anim)` | ✅ 돔틸트 | ✅ 재조준 | ✅(90=중앙) | 돔 기울기(관람 30 / 전천 0 / 천정 90) |
| `setPositionLBR(Vec,Anim,track)` | 🛑 금지 | ✅ 위치이동 | ✅ 위치 | 프레임 내 카메라 위치(옆도킹·오빗) |
| `setPositionR(R, Anim, track)` | 🛑 무효 | ✅ 거리줌 | 🛑 무효(고정투영) | 대상 거리(줌인/풀백) = 읽은값×배율 |
| `setOrientationSmoothXYZR(Vec4,Anim,track)` | — | ✅ 필수 | ✅ 조준 | 프레임 전환 직후 시선 정렬(안 하면 뒤틀림) |
| `setOrientationHPR(Vec(H,P,R),Anim)` | △ | △ | ✅ Roll스핀 | 시선축(Roll=셋째값) 회전 = 팽이 스핀 |
| `setZoomFov(fov, Anim)` | 🛑 무효 | ✅ 광학줌 | ✅ | FOV 광학 줌(카메라 안 움직임) |
| `setZoomPosition + setZoomFormula` | 🛑 무효 | ✅ 줌락 | ✅ 조준유지 | 이동 중 대상 중앙 자동 유지(줌 락) |
| `obj.setScale(orig×배율, Anim)` | ✅ 클로즈업 | ✅ | ✅ 성단확대 | 위치줌 안 되는 데서 개체 자체를 키움 |
| `data.action(FadeTo)` | ✅ 진입 | ✅ | ✅ | 페이드 전환(비행 아님). 행성 R=5, 성단 R=0 |
| `data.action(GoTo)` | ✅ 출발 | ✅ 도착 | (행성계) | 연속 비행(우주선 여행). 도착 R≈5 |
| `data.action(ConnectTo)` | ✅ | ✅ | ✅ | 이동 없이 프레임만 순간 전환(흔들림 無) |
| `dm.setDateTime(..., Anim)` | ✅ 하늘회전 | ✅ 자전 | — | 시간가속 = 하늘/천체 회전 연출 |

✅=권장 동작 / △=되지만 부자연/특수 / 🛑=이 프레임에선 무효·금지

## 📖 명령어별 상세 (상황 + 사용법)

### 1. `setOrientationH(H, Anim)` — 지상 좌우 조준
- **어디서**: ① 지상 Sky View 전용.
- **상황**: 지상 밤하늘에서 특정 천체(태양·달·별자리)를 화면 중앙으로.
- **사용법**: `H = 180 − 천체방위(나침반)`. 태양 방위 285.5° → `setOrientationH(-105.5)`. + `setTargetHeight(30)`.
- **함정**: 우주 프레임에선 의미 다름. 예제 `cam_01`.

### 2. `setTargetHeight(t, Anim)` — 돔 틸트(Target)
- **어디서**: 전 프레임. **t는 천체 고도가 아니라 '돔 기울기'.**
- **상황**: 관람 표준 **30** / 전천 그리드 **0** / 천정 클로즈업·성운중앙 **90**.
- **함정**: 같은 값 재호출은 no-op → 재조준은 `29.9→30` 지글. 예제 `cam_02`.

### 3. `setPositionLBR(Vec(L,B,R), Anim, track)` — 프레임 내 위치
- **어디서**: ② 행성/우주 · ③ 성운. **🛑 지상 Sky View 금지**(관측자 이탈).
- **상황**: FadeTo 행성 후 옆도킹/오빗(L=경도스윕, B=위도틸트), R=거리.
- **사용법**: `track` **필수**(최소 `-1`). R단위=**트랙 대상 반지름**(km 아님). 절대값 금지 → 읽은값×배율.
- 예제 `cam_03`.

### 4. `setPositionR(R, Anim, track)` — 거리(줌인/풀백)
- **어디서**: ② 행성/우주 전용. 🛑 성단(고정투영)·지상 무효.
- **사용법**: `p = cam.positionLBR` → `setPositionR(p.z * 0.5, Anim, -1)`(줌인) / `p.z * 12`(풀백). track=-1=현프레임 유지.
- 예제 `cam_04`.

### 5. `setOrientationSmoothXYZR(Vec4(0,0,0,0), Anim, track)` — 시선 정렬
- **어디서**: 프레임 전환 직후 **반드시**.
- **상황**: 관성 프레임(EquatorialJ2000)·태양 top-down 등으로 `setPositionLBR(...,port)` 옮긴 직후 같이 호출. 안 하면 "시점 병신".
- 예제 `cam_05`.

### 6. `setOrientationHPR(Vec(H,P,R), Anim)` — 시선축 회전
- **어디서**: ③ 성운/성단 내부 둘러보기·회전.
- **사용법**: **H=좌우팬 / P=위아래 / R(셋째값)=Roll=시선축 팽이 스핀**. 진짜 '회전'은 R+360.
- **함정**: 성단 별밭은 위치(L/R)에 반응 안 함 → 회전은 이 orientation 으로만. 예제 `cam_06`.

### 7. `setZoomFov(fov, Anim)` — 광학 FOV 줌
- **어디서**: ② 우주/행성 뷰. 🛑 지상 Sky View 무효.
- **상황**: 카메라 안 움직이고 화각만 좁혀 확대(110→60). '뷰 축' 기준이라 Target 30 구도엔 부적합.
- 예제 `cam_07`.

### 8. `setZoomFormula(GreatCircle)` + `setZoomPosition(Vec, track, Anim, PositionMode.XYZ)` — 줌 락
- **어디서**: ② 우주 · ③ 성운. 🛑 지상 무효.
- **상황**: 카메라가 이동해도 대상을 화면 중앙에 자동 유지(엔진이 재조준). 근접 공전 등.
- 예제 `cam_08`.

### 9. `obj.setScale(orig×배율, Anim)` — 개체 확대
- **어디서**: 위치 줌이 안 되는 데(지상 클로즈업, 성단 내부).
- **사용법**: `orig = obj.scale` **먼저 읽고**(⚠️성단은 FadeTo '전' 지상에서 읽어야 실제값) → `setScale(orig*25~700, Anim)`. **절대값 금지**(원본이 1.0 아닐 수 있음).
- 예제 `cam_09`.

### 10. `data.action(Action.Type.FadeTo).trigger()` — 페이드 전환
- **뭐냐**: 비행 아님. Fade out→순간이동→Fade in. 행성 R=5 도킹 / 성운·성단 R=0.
- **상황**: 프레임 간 전환(지상↔행성). 슬루 숨기려면 GlobalIntensity 0 에서.
- 예제 `cam_10`.

### 11. `data.action(Action.Type.GoTo).trigger()` — 연속 비행
- **뭐냐**: 현 위치→대상까지 실제 비행(우주선 여행). 도착 R≈5.
- **상황**: '날아가는' 연출. ⚠️ 비행 중 자세회전 1회 흔들림 내장. 도착 후 `setTargetHeight(30)` 필수.
- **⚠️ action 이 None 이면 그 데이터는 GoTo 미지원** → FadeTo/ConnectTo 로.
- 예제 `cam_11`.

### 12. `data.action(Action.Type.ConnectTo).trigger()` — 프레임만 전환
- **뭐냐**: 카메라 이동 없이 대상 트랙 프레임으로 순간 전환(흔들림 無).
- **상황**: 흔들림 없는 줌인 = ConnectTo(암전 속) + 이후 setPositionR 애니.
- 예제 `cam_12`.

### 13. `dm.setDateTime(목표, tz, Anim(초))` — 시간가속(하늘 회전)
- **뭐냐**: 카메라 명령은 아니지만 '회전 연출'의 정답. 시간이 흐르며 하늘/천체가 실제 회전.
- **상황**: 지상 천구회전(일주), 행성 자전(관성프레임+setRotationSpeedScale 병행), 일식 진행.
- **함정**: 지상 다년 가속=자전 광란. 시/일 단위는 부드러움. 예제 `cam_13`.

## 🎯 "이럴 땐 이거" 빠른 처방
- **지상서 천체 조준** → `setOrientationH` + `setTargetHeight(30)`
- **행성 줌인** → FadeTo → `p=cam.positionLBR; setPositionR(p.z*0.5, Anim, -1)`
- **행성 풀백/이탈** → `setPositionR(p.z*12, Anim, -1)`
- **성운/성단 회전** → `setOrientationHPR(Vec(H,P,R+360), Anim)` (Roll)
- **성단 확대** → 지상서 `orig=gc.scale` 읽고 → FadeTo → `setScale(orig*700, Anim)`
- **지상 클로즈업(일식 코로나 등)** → `setScale`(FOV줌·위치줌 다 무효)
- **우주선 여행 느낌** → `GoTo`(비행) / 흔들림 없이 → `ConnectTo`+`setPositionR`
- **하늘/천체 돌리기** → `setDateTime` 시간가속
