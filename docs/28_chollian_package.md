## 2. 설치

### 2-1. 모델 만들기 (최초 1회)

1. Studio 에 `make_chollian_model.py` 를 드래그앤드롭 → 데이터베이스 스크립트 → 더블클릭 실행
2. 로그에서 이 두 줄을 확인한다:
   ```
   ✓ chollian.osg  ...바이트
   ✅ chollian.osg  status=Loaded  radius=5.27...
   ```
3. 파일은 **유저 폴더**에 생긴다: `D:/SkyExplorer-Data/user/chollian.osg`

> 폴더 경로가 다른 설치라면 스크립트가 로그 첫머리에 실제 경로를 찍는다
> (`Configuration.configuration().localUserFolder`). 그 경로를 믿으면 된다.

⚠️⚠️ **경로 규약이 두 가지라 헷갈리기 쉽다:**
- **우리가 넣는 자산**(모델·이미지·텍스처) = **유저 폴더** 기준. 파일명만 써도 되고 절대경로도 된다
- **Studio 기본 자산**(`..\data\scene\astronomy\...`) = 그 **유저 폴더의 부모** 기준
  (`D:\SkyExplorer-Data\data\`). 블랙홀 모델 경로가 그래서 `..\data\` 로 시작한다

### 2-2. 쇼 넣기

`SHOW_chollian.py` 를 같은 방법으로 Studio 에 가져온다. 실행은 더블클릭.

## 4. 실패 시 대처

**1번(우주 장면에서 자막이 안 뜬다) — 두 번 연속 이걸로 깨졌다**

- 프레임마다 **자막 규칙이 반대**다: **지상 = `setSize(0.052)` + `setDistance(1.0)` /
  우주 = 크기를 만지지 말고 `setDistance(20)`**
- ⚠️⚠️ **핵심은 '`setSize` 를 안 부르는 것'이 아니라 '슬롯을 갈아타는 것'이다.**
  크기를 되돌리는 API 가 없어서, 지상에서 크기를 걸어 둔 슬롯을 우주에서 다시 잡으면
  **호출을 안 해도 자막이 사라진다**(v3 가 정확히 이걸로 죽었다 — 범례는 새 슬롯이라 떴고
  본 자막만 안 떴다)
- 이 쇼는 `SLOT_GROUND = 1` / `SLOT_SPACE = 5` 로 고정돼 있다. **이 둘을 섞지 마라**
- 린터에 규칙이 두 개 들어가 있다(같은 객체 / 슬롯을 인자로 받는 헬퍼). 고쳤으면 먼저 돌려 볼 것

**3·4번(지구가 안 돌거나, 위성이 튄다) — 프레임 문제다**

이 쇼는 **프레임 세 개**를 구분해서 쓴다. 섞으면 바로 깨진다:
- **관성(`ip` = EquatorialJ2000)** = 카메라의 집. 여기 있어야 **지구가 도는 게 보인다.**
  FadeTo 도킹 프레임에 그냥 두면 카메라가 자전을 따라 돌아 **지구가 멈추고 하늘이 돈다**
- ⚠️ 프레임 이동은 **반드시 두 줄** — `setPositionLBR(..., 포트)` **+ `setOrientationSmoothXYZR(...)`**.
  둘째 줄을 빼면 카메라가 대상 없는 쪽을 봐서 **화면이 텅 빈다**(실제로 그랬다). 헬퍼 `fly()` 를 쓸 것
- **동기(`sp` = EquatorialSynchronous)** = 위성의 집. 이 프레임의 경도 = 지구 경도라
  **128.2 를 넣으면 한반도 위에 자동으로 붙는다.** 위성을 손으로 밀지 마라 — 시간가속과 겹쳐 **급발진**한다

**7번(위성이 안 보인다)**

**이 순서대로** 의심한다 — 배율은 맨 마지막이다:

1. **구도.** 각도(`B_TOP`=88)를 건드렸는지 본다. 비스듬하면 화면 밖으로 밀린다
2. **거리.** `R_FAR`(20)에서 출발해 `R_ORBIT`(8)까지 다가간다. 20 에 머무르게 두지 마라
3. **렌더.** 지구가 안 보이면 `setTerrainIntensity` — 0 이면 **가까이 갈수록 사라진다**
4. **모델 로드.** 로그에 `⚠️ 모델 로드 실패` 가 있으면 2-1 을 다시 한다
5. **배율.** `SCALE_SAT = 1.0e6` (반지름 5,270 km)

**궤도선은 마지막 장면에만 있다**
- `OrbitalPlace` 궤도선이 **가까이서는 끊겨 보인다**(위성을 꺼도, 굵기를 올려도 — 프로브 확인).
  그래서 막1~4 에서는 안 쓰고, **멀리서 보는 막5 에서만** 굵게(3.0) 그린다.
  금색 = 일하던 자리 / 회색 = 무덤 궤도. 여기서도 끊겨 보이면 `ring()` 호출을 지우면 된다

**색이 안 나온다**
- ✅ **해결됐다** — `.osg` 의 `Geometry` 안에 `StateSet{ Material{ diffuseColor } }` 를 넣으면 나온다.
  `ColorArray` 만으로는 안 먹는다(조명이 켜져 있어 재질 기본 흰색이 이긴다).
- `make_chollian_model.py` 를 **다시 한 번 돌리면** `chollian.osg` 가 색 판으로 덮어써진다.
  쇼 코드는 안 바뀐다. 흰색으로 나오면 생성기를 안 돌린 것이다

**모델 로드가 실패한다**
- 유저 폴더 경로를 로그에서 확인한다. 생성기가 찍는 경로가 진실이다
- 로그가 `Loading` 에서 멈춘 것처럼 보여도 실패가 아닐 수 있다 — 이 쇼는 `Loaded` 가 뜰 때까지
  최대 12초 폴링한다. 12초를 넘겼다면 진짜 실패다

**쇼가 중간에 멈춘다**
- 막마다 `try/except` 로 감싸 놨다. 로그의 `막N 오류:` 를 보면 어디서 죽었는지 나온다
- 그 막만 건너뛰고 다음 막이 이어지므로 상영 자체는 계속된다

**앞 쇼의 마지막 화면이 번쩍인다**
- 이 쇼는 암전을 `reset` 보다 먼저 걸고 클램프로 눌러 둔다. 그래도 보인다면
  Studio 에서 앞 쇼를 완전히 정지한 뒤 실행한다

## 5. 조정하고 싶을 때

| 바꾸고 싶은 것 | 건드릴 곳 | 주의 |
|---|---|---|
| 위성 크기 | `SCALE_SAT` | 1e6(반지름 5,270km). **R 을 바꾸면 배율도 같은 비율로** — 안 그러면 겉보기 크기가 달라진다 |
| 비행 구간 | `R_FAR`(20) → `R_ORBIT`(8) / 줌인 `R_ZOOM_A`(9)→`R_ZOOM_B`(7.6) / `R_DIVE`(3.2) → `R_BACK`(9) | **각도(`B_TOP`=88)는 건드리지 마라** — 프레이밍이 깨진 건 세 번 다 각도였다 |
| 지구 클로즈업 | `B_NEAR`, `R_NEAR` | 프레이밍이 바뀌므로 암전 안에서만 |
| 무덤 궤도 높이 | `GRAVE_MM`, `GRAVE_R` | 둘을 같이 바꿔야 궤도선과 위성이 맞는다 |
| 자막 속도 | `say()` 의 자동 계산 | `2초 + 글자당 0.1초`. 숫자를 직접 박지 마라 |
| 관측지·시각 | 막0 의 `Place2D.setPosition` / `setDateTime` | **시각은 UTC**. 청주 22시 = 13:00 UTC |

## 6. 알려진 제약

- **소리**: 스크립트로 못 낸다(엔진 확정). 관 음향으로 입힌다
- **축척 과장 3곳**: 위성 크기(1:23), 무덤 궤도 높이(4:26), 2A·2B 경도(겹쳐 보여 벌림). 둘 다 나레이션에서 고지한다 — 빼지 말 것
- **모델 색**: 금색 단열재 본체 · 짙은 남색 태양전지판 · 흰 안테나 (Material 방식, 확인됨)
- **검증 상태**: **돔 재생 4회 + 프레임 프로브 1회.** 프로브로 관성 프레임·동기 프레임 위성·진짜 줌인 세 가지를 확인했고(궤도선은 못 쓴다는 것도), v5 는 그 위에 다시 짰다. **통짜 재생은 아직 안 해 봤다.**
  첫 상영 전에 반드시 리허설한다. 확인 후 스크립트 첫머리의 `# 검증:` 줄을 갱신하고
  `tools/ledger.py` 로 원장에 올린다
