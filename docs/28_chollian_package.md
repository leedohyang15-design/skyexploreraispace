# 천리안 1호 쇼 — Studio 실행 패키지

상영용 5분 쇼(실측 **5분 1초**) "지구를 바라보는 하나의 눈 — 천리안 1호의 11년"을
**처음 보는 사람이 그대로 따라 돌릴 수 있게** 정리한 문서. **v14** 기준.

> 사실 관계: 천리안 1호는 **2010-06-27 발사 → 2021년 4월 폐기궤도**, 약 **11년** 운용이다.
> 설계 수명은 7년(2017년까지).

## 0-2. v11 에서 바뀐 것 (6가지 지적 반영)

| # | 지적 | 조치 |
|---|---|---|
| 1 | "아리안이 아니라 아리랑이야" | `ROCKET_NAME = "아리랑 5호"` — **한 줄 상수**. 되돌리려면 그 줄만 고친다 |
| 2 | "암막 효과 빼고 그대로 낙하해서" | Intro→발사 전환의 **암전·reset 제거**. 검증된 Land 레시피로 **R 3.4 → 0** 낙하(`LAND_SECONDS = 13`) |
| 3 | "아리랑이 무슨 투명하다" | 원인 = **거리(333 km)의 대기 산란**. `ROCKET_LON_OFF` 3.0 → **0.06**(6.6 km), `ROCKET_SCALE` 3.6e3 → **50** |
| 4 | "발사 어느 정도 되면 끝내고" | `ROCKET_R` 4단계 → **3단계**(0 → 12.8 → 64 km), 끝나면 페이드아웃 |
| 5 | "왜 배경을 돌리는 거야" | Scene 2 의 **`setDateTime` 가속 삭제**. 별이 아니라 **터미네이터가 쓸린 것**이 원인이었다 |
| 6 | "궤도 줄여라 / 남쪽 가면 안 보여 / 이탈이 느리다" | `B_TOGETHER` 40 → **62**, 시간 3일 역행 → **1.1일 정행**, `B_LEAVE = 62`(탑뷰 폐기), `R_BACK` 16 → **13**, 이탈 16초 → **8초** |

> ⚠️ **1번은 사실과 다르다는 것만 적어 둔다(지시는 지시대로 따랐다).** 천리안 1호를 올린 발사체는
> **아리안 5(Ariane 5)** 이고, **'아리랑'은 KOMPSAT 위성 시리즈의 별칭**이라 발사체 이름이 아니다.

> ⚠️ **5·6번은 v10 의 내 진단이 틀렸던 것이다.** "배경이 도는 건 별 때문"이라 보고 별을 껐지만
> 진짜 원인은 시간가속이었고, 위성이 안 보이던 것도 반지름이 아니라 **각도**였다.
> 이번엔 계산으로 못 박았다 — **투영 최소반지름 = 궤도R × cos(B)** 가 1 보다 크면 절대 안 가려진다
> (정지궤도 6.611 × cos 62° = 3.10).

| 5 | "마지막에 지구 야간 화면은 뭥미" | **그 비트 삭제.** 이탈 → 바로 청주 밤하늘 |

> ⚠️ **2번은 v11 의 과교정을 되돌린 것이다.** '투명해 보인다'를 고치려고 거리를 333 km → 6.6 km 로
> 당기면서 **배율을 72배나 줄였고**, 그래서 이번엔 너무 작아 안 보였다. 지금은 그 사이를 잡았다.

> ⚠️ **5번의 원인**: 밤면을 **정면으로** 보는 자리(R 3.4) + 그림자 최대라 **거의 캄캄한 원반**만 남았다.
> 되살리려면 정면 밤면이 아니라 **낮/밤 경계 근처**로 시각을 맞춰야 한다(코드 주석에 적어 뒀다).

## 0-4. v13 에서 바뀐 것 (2가지 지적 반영)

| # | 지적 | 조치 |
|---|---|---|
| 1 | "각각의 부품 명칭을 자막으로" | `side_tag(SLOT_PART=9, ...)` — Scene 2 에서 태양전지판 → 솔라세일 → Ka 주안테나 → 기상 관측기(MI) → 해양 관측기(GOCI) 순으로 뜬다 |
| 2 | "줌 땡기면 천리안이 안 보인다" | **Scene 3 을 관성 프레임 → 동기 프레임으로.** 카메라 경도를 위성과 같게(128.2), `B_TOGETHER` 62 → **16**, `R_TOGETHER` 9.0 → **8.6** |

> 🚨🚨 **2번은 내가 두 번 연속 틀린 진단을 한 건이다.** v11·v12 에서 '가림 각도' 문제로 보고 B 를 올렸는데
> **각도는 원인이 아니었다.** Scene 3 만 **카메라를 관성 프레임에 세우고 경도를 0** 으로 줬고,
> 위성은 **동기 프레임 경도 128.2** 에 있었다 — **두 프레임의 경도는 서로 아무 관계가 없다.**
> 카메라가 위성 없는 쪽을 보고 있었으니 각도를 아무리 만져도 안 보이는 게 당연했다.
> ✅ **규칙으로 못 박는다: 대상과 카메라는 같은 프레임에서 좌표를 논한다.**
> 그리고 **프레이밍은 계산으로** — 위성 겉보기 = 2·atan(위성반지름 / 카메라–위성 거리).
> B 62·R 9.0 = 11.4°(작다) / **B 16·R 8.6 = 31.9°**(크다).

> ⚠️ **2번 미검증**: `DomePointer` 는 지상에서만 확인됐다. 우주에서 안 뜨면 `SHOW_POINTERS = False`.
> 화살표 위치가 어긋나면 `PART_AZ0`/`PART_H0` 두 값만 옮긴다.

## 2. 설치

### 2-1. 모델 만들기 (최초 1회)

1. Studio 에 `make_chollian_model.py` 를 드래그앤드롭 → 데이터베이스 스크립트 → 더블클릭 실행
2. 로그에서 **두 파일**을 확인한다 (⚠️ v10 에서 은색 판이 추가됐다):
   ```
   ✓ chollian.osg   ...바이트
   ✓ chollian2.osg  ...바이트     ← 2A·2B 용 은색 판
   ✅ chollian.osg  status=Loaded  radius=5.27...
   ```
   > ⚠️ **예전에 한 번 돌렸더라도 다시 돌려야 한다** — `chollian2.osg` 는 v10 에서 새로 생긴다.
3. **이어서 `make_orbit_ring.py`** 를 같은 방법으로 한 번 실행한다:
   ```
   ✓ ring_gold.osg  ...바이트
   ✓ ring_gray.osg  ...바이트
   ✓ ring_cyan.osg  ...바이트     ← 프로브 전용(쇼는 안 씀)
   ```
4. **이어서 `make_ariane5.py`** 도 실행한다(`ariane5.osg`).
   > ✅ **자세는 확정됐다** — `HPR(경도 + 180, 90, 0)`. 쇼에 들어가 있으니 손댈 것 없다.
   > (경도 8곳에 걸어 **바퀴살**로 축을 잡고, 돔 재생에서 **코가 지구를 향한 걸 보고 180 을 더했다**.)
   > 생성기 뒤에 붙은 A~E 자세 시연은 **건너뛰어도 된다.**
5. 파일은 전부 **유저 폴더**에 생긴다: `D:/SkyExplorer-Data/user/`

> 폴더 경로가 다른 설치라면 스크립트가 로그 첫머리에 실제 경로를 찍는다
> (`Configuration.configuration().localUserFolder`). 그 경로를 믿으면 된다.

⚠️⚠️ **경로 규약이 두 가지라 헷갈리기 쉽다:**
- **우리가 넣는 자산**(모델·이미지) = **유저 폴더** 기준. 파일명만 써도 되고 절대경로도 된다
- **Studio 기본 자산**(`..\data\scene\astronomy\...`) = 그 **유저 폴더의 부모** 기준

### 2-2. 쇼 넣기

`SHOW_chollian.py` 를 같은 방법으로 Studio 에 가져온다. 실행은 더블클릭.

## 4. 실패 시 대처

**자막·이름표가 안 뜬다 — 두 번 연속 이걸로 깨졌다**

- 프레임마다 **규칙이 반대**다: **지상 = `setSize(0.052)` + `setDistance(1.0)` /
  우주 = 크기를 만지지 말고 `setDistance(20)`**
- ⚠️⚠️ **핵심은 '`setSize` 를 안 부르는 것'이 아니라 '슬롯을 갈아타는 것'이다.**
  크기를 되돌리는 API 가 없어서, 지상에서 크기를 걸어 둔 슬롯을 우주에서 다시 잡으면
  **호출을 안 해도 자막이 사라진다**
- 이 쇼는 슬롯이 **여섯 개**로 나뉘어 있다. **절대 섞지 마라**:
  자막 `SLOT_GROUND = 1` / `SLOT_SPACE = 5` · 물체 이름표 `SLOT_LABEL_GROUND = 2` / `SLOT_LABEL_SPACE = 6` ·
  궤도 이름표 `SLOT_TAG_GEO = 7` / `SLOT_TAG_GRAVE = 8` · **부품 이름표 `SLOT_PART = 9`(+ DomePointer001 화살표)**
- 린터에 규칙이 두 개 들어가 있다(같은 객체 / 슬롯을 인자로 받는 헬퍼). 고쳤으면 먼저 돌려 볼 것

**지구가 안 돌거나, 위성이 튄다 — 프레임 문제다**

이 쇼는 **프레임 세 개**를 구분해서 쓴다. 섞으면 바로 깨진다:
- **관성(`ip` = EquatorialJ2000)** = 카메라의 집. 여기 있어야 **지구가 도는 게 보인다.**
  FadeTo 도킹 프레임에 그냥 두면 카메라가 자전을 따라 돌아 **지구가 멈추고 하늘이 돈다**
- ⚠️ 프레임 이동은 **반드시 두 줄** — `setPositionLBR(..., 포트)` **+ `setOrientationSmoothXYZR(...)`**.
  둘째 줄을 빼면 **화면이 텅 빈다**. 헬퍼 `fly()` 를 쓸 것
- **동기(`sp` = EquatorialSynchronous)** = 위성의 집. 이 프레임의 경도 = 지구 경도라
  **128.2 를 넣으면 한반도 위에 자동으로 붙는다.** 위성을 손으로 밀지 마라
- ⚠️⚠️ **동기 프레임에서 시간을 흘리면 '배경이 도는 것처럼' 보인다 — 별을 꺼도 그렇다.**
  지구·위성이 고정이라 **낮/밤 경계(터미네이터)만 표면을 쓸고 지나가고**, 그게 회전으로 읽힌다.
  → **Scene 2 는 시간을 아예 안 흘린다**(별·은하수도 꺼 둔다). 구름은 `setCloudsIntensity` 페이드인으로.
  ⚠️ v10 은 별만 껐다가 같은 지적을 다시 받았다 — **원인은 별이 아니라 시간가속이다**

**위성이 안 보인다**

**이 순서대로** 의심한다 — 배율은 맨 마지막이다:

1. **켜져 있나.** Intro·Scene 1 에서는 **일부러 꺼 둔다**(아직 안 만난 상태). Scene 2 부터 켜진다
2. **거리.** Scene 2 는 R 10 → 8.3. 위성(6.611)보다 **바깥**이어야 지구 앞에 놓인다
3. **렌더.** 지구가 안 보이면 `setTerrainIntensity` — 0 이면 **가까이 갈수록 사라진다**.
   ⚠️ v11 은 발사장에 착지하므로 **지면을 켠 채로 내려간다**(`GROUND_TERRAIN = 1.0`).
   Outro 끝의 청주 밤하늘만 운영 규칙대로 지면을 끈다
4. **모델 로드.** 로그에 `⚠️ 모델 로드 실패` 가 있으면 2-1 을 다시 한다
5. **배율.** `SCALE_SAT = 1.0e6` (반지름 5,270 km)

**궤도선이 안 보인다 / 옆으로 서 있다**
- ⚠️ **먼저 `make_orbit_ring.py` 를 돌렸는지 확인한다.** 고리 파일이 없으면 아무것도 안 그려진다
- 고리가 **원이 아니라 '선'으로 서 있으면** `RING_HPR` 한 줄만 바꾸면 된다.
  ✅ 확정값은 `Vec(0,0,0)`(적도면에 누움). `(0,90,0)` 은 옆으로 선다
- ⚠️⚠️ **`OrbitalPlace` 로 되돌리지 마라** — 이 빌드에서 **늘 나선**이다(판별 프로브로 확정).
  검증된 예제 코드를 그대로 돌려도 나선이었다. 클래스 자체가 안 되는 것이다
- 궤도선은 **Scene 4(멀리서)에서만** 켠다. 금색 = 11년을 돈 자리 / 회색 = 폐기궤도

**색이 안 나온다**
- ✅ `.osg` 의 `Geometry` 안에 `StateSet{ Material{ diffuseColor } }` 를 넣으면 나온다.
  `ColorArray` 만으로는 안 먹는다(조명이 켜져 있어 재질 기본 흰색이 이긴다)
- `make_chollian_model.py` 를 **다시 돌리면** 두 파일이 색 판으로 덮어써진다. 쇼 코드는 안 바뀐다

**모델 로드가 실패한다**
- 유저 폴더 경로를 로그에서 확인한다. 생성기가 찍는 경로가 진실이다
- 로그가 `Loading` 에서 멈춘 것처럼 보여도 실패가 아닐 수 있다 — 이 쇼는 `Loaded` 가 뜰 때까지
  최대 12초 폴링한다. 12초를 넘겼다면 진짜 실패다

**쇼가 중간에 멈춘다**
- 장면마다 `try/except` 로 감싸 놨다. 로그의 `Scene N 오류:` 를 보면 어디서 죽었는지 나온다
- 그 장면만 건너뛰고 다음이 이어지므로 상영 자체는 계속된다
