## 1. 구성물

| 파일 | 역할 | 위치 |
|---|---|---|
| `scripts/golden/SHOW_chollian.py` | **쇼 본편** (4분 59초) | Studio 로 가져온다 |
| `scripts/study/make_chollian_model.py` | **위성 모델 생성기** — 유저 폴더에 모델 파일을 쓴다 | Studio 로 가져온다 (한 번만 실행) |

Studio 파이썬이 파일을 쓸 수 있다는 게 확인돼 있어(2026-08-12 실측) 손으로 복사할 일이 없다.

## 2. 설치

### 2-1. 모델 만들기 (최초 1회)

1. Studio 에 `make_chollian_model.py` 를 드래그앤드롭 → 데이터베이스 스크립트 → 더블클릭 실행
2. 로그에서 이 두 줄을 확인한다:
   ```
   ✓ chollian.osg  ...바이트
   ✅ chollian.osg  status=Loaded  radius=5.27...
   ```
3. 파일은 **유저 폴더**에 생긴다: `D:/SkyExplorer-Data/user/chollian.osg`

> 폴더 경로가 다른 설치라면 스크립트가 로그 첫머리에 실제 경로를 찍는다
> (`Configuration.configuration().localUserFolder`). 그 경로를 믿으면 된다.

⚠️⚠️ **경로 규약이 두 가지라 헷갈리기 쉽다:**
- **우리가 넣는 자산**(모델·이미지·텍스처) = **유저 폴더** 기준. 파일명만 써도 되고 절대경로도 된다
- **Studio 기본 자산**(`..\data\scene\astronomy\...`) = 그 **유저 폴더의 부모** 기준
  (`D:\SkyExplorer-Data\data\`). 블랙홀 모델 경로가 그래서 `..\data\` 로 시작한다

### 2-2. 쇼 넣기

`SHOW_chollian.py` 를 같은 방법으로 Studio 에 가져온다. 실행은 더블클릭.

## 4. 실패 시 대처

**1번(우주 장면에서 자막이 안 뜬다) — 두 번 연속 이걸로 깨졌다**

- 프레임마다 **자막 규칙이 반대**다: **지상 = `setSize(0.052)` + `setDistance(1.0)` /
  우주 = 크기를 만지지 말고 `setDistance(20)`**
- ⚠️⚠️ **핵심은 '`setSize` 를 안 부르는 것'이 아니라 '슬롯을 갈아타는 것'이다.**
  크기를 되돌리는 API 가 없어서, 지상에서 크기를 걸어 둔 슬롯을 우주에서 다시 잡으면
  **호출을 안 해도 자막이 사라진다**(v3 가 정확히 이걸로 죽었다 — 범례는 새 슬롯이라 떴고
  본 자막만 안 떴다)
- 이 쇼는 `SLOT_GROUND = 1` / `SLOT_SPACE = 5` 로 고정돼 있다. **이 둘을 섞지 마라**
- 린터에 규칙이 두 개 들어가 있다(같은 객체 / 슬롯을 인자로 받는 헬퍼). 고쳤으면 먼저 돌려 볼 것

**7번(위성이 안 보인다)**

세 번 다른 이유로 겪었다. **이 순서대로** 의심한다 — 배율은 맨 마지막이다:

1. **구도.** 비스듬한 각도(B=35)에서는 정지궤도가 화면 밖으로 밀린다. 이 쇼는 **북극 위 B=88** 에서
   시작한다(`B_TOP`). 링이 원형이라 안 잘린다
2. **거리.** 이 쇼는 `R_FAR`(20)에서 출발해 `R_ORBIT`(8)까지 **다가간다**. 20 은 지구가
   각지름 5.7° = 점이라 **출발점으로만** 쓴다 — 거기 머무르게 두지 마라
3. **렌더.** 지구가 안 보이면 `setTerrainIntensity` 를 의심한다 — 0 이면 **가까이 갈수록 사라진다**
4. **모델 로드.** 로그에 `⚠️ 모델 로드 실패` 가 있으면 2-1 을 다시 한다
5. **배율.** `SCALE_ORBIT = 5.0e5` (위성 반지름 2,636 km). R 을 바꾸면 **배율도 같이** 바꿔야
   겉보기 크기가 유지된다(거리 절반 → 배율 절반)

**모델 로드가 실패한다**
- 유저 폴더 경로를 로그에서 확인한다. 생성기가 찍는 경로가 진실이다
- 로그가 `Loading` 에서 멈춘 것처럼 보여도 실패가 아닐 수 있다 — 이 쇼는 `Loaded` 가 뜰 때까지
  최대 12초 폴링한다. 12초를 넘겼다면 진짜 실패다

**색이 흰색이다 — 정상이다**
- 현재 모델은 **흰-은색**이다. 엔진 조명이 켜져 있어 모델의 정점 색이 무시된다(재질 미적용).
- 실제 위성도 흰 단열재와 은색 몸체라 틀린 그림은 아니다. 금색 태양전지판은 재질 문법을 확인한 뒤 추가 예정
- 색이 들어와도 **쇼 코드는 바뀌지 않는다** — 모델 파일만 갈아 끼우면 된다

**쇼가 중간에 멈춘다**
- 막마다 `try/except` 로 감싸 놨다. 로그의 `막N 오류:` 를 보면 어디서 죽었는지 나온다
- 그 막만 건너뛰고 다음 막이 이어지므로 상영 자체는 계속된다

**앞 쇼의 마지막 화면이 번쩍인다**
- 이 쇼는 암전을 `reset` 보다 먼저 걸고 클램프로 눌러 둔다. 그래도 보인다면
  Studio 에서 앞 쇼를 완전히 정지한 뒤 실행한다

## 5. 조정하고 싶을 때

| 바꾸고 싶은 것 | 건드릴 곳 | 주의 |
|---|---|---|
| 위성 크기 | `SCALE_ORBIT`(궤도) / `SCALE_CLOSE`(클로즈업) | 5e5 / 4e6. **R 을 바꾸면 배율도 같은 비율로** — 안 그러면 겉보기 크기가 달라진다 |
| 비행 구간 | `R_FAR`(20) → `R_ORBIT`(8) → `R_DIVE`(3.2) → `R_BACK`(9) | **각도(`B_TOP`=88)는 건드리지 마라** — 프레이밍이 깨진 건 세 번 다 각도였다 |
| 지구 클로즈업 | `B_NEAR`, `R_NEAR` | 프레이밍이 바뀌므로 암전 안에서만 |
| 무덤 궤도 높이 | `GRAVE_MM`, `GRAVE_R` | 둘을 같이 바꿔야 궤도선과 위성이 맞는다 |
| 자막 속도 | `say()` 의 자동 계산 | `2초 + 글자당 0.1초`. 숫자를 직접 박지 마라 |
| 관측지·시각 | 막0 의 `Place2D.setPosition` / `setDateTime` | **시각은 UTC**. 청주 22시 = 13:00 UTC |
