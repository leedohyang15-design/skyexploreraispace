## ① `scripts/golden/SHOW_perseids.py` — 오늘 밤이 극대 (약 2분 12초)

**시의성이 있는 유일한 항목.** 내일이면 평범한 쇼가 됩니다.

| 볼 것 | 왜 |
|---|---|
| [ ] 유성이 **한 점에서 방사**되나 | `setReferential(RaDec)` 가 먹었는지. 이게 안 먹으면 아무 방향에서나 튀어나온다 |
| [ ] 그 점이 **페르세우스자리 위**인가 | 복사점 좌표(적경 47 / 적위 58)가 맞는지 |
| [ ] **ZHR 900 이 성긴가 / 적당한가** | 실제값 100 은 돔에서 안 보여 900 으로 올렸다. 성기면 1500 으로 올린다 |
| [ ] 극대의 **2400 이 과한가** | 과하면 1800 으로. "비 오듯" 이 목표지 "화면이 하얘짐"이 아니다 |
| [ ] 북동 하늘에 페르세우스가 **떠 있나** | `H=135`(북동) + 틸트 22 로 잡았다. 지평선 아래면 시각/방위를 다시 계산해야 한다 |

⚠️ 복사점이 화면 밖이면 **유성은 나오는데 어디서 오는지 안 보인다** — 이 쇼의 핵심이 죽습니다.
그 경우 `H_NORTHEAST` / `TILT` 값을 알려주시면 조정합니다.

| [ ] **30초 무자막 구간이 지루한가** | 새 린터가 여기를 잡았다. 45초 중 30초라 비중이 크다 |

⚠️ **이 파일은 고치지 마세요.** "AI 가 만든 것 그대로, 사람이 손댄 곳 없음"이 시연 포인트입니다.
30초 구간이 지루했다면 손으로 고치는 대신 **갱신된 Space 에서 같은 문장으로 다시 생성**해 주세요:

```
청주에서 지구 자전으로 별이 도는 걸 보여줘
```

오늘 자막 템포 규칙이 들어갔으니 새 버전은 자막을 쪼개서 낼 겁니다.
그러면 **"규칙을 넣었더니 결과가 이렇게 달라졌다"** 는 비교 자료가 통째로 생깁니다(시연에서도 좋은 소재).

## 끝나고

세 줄만 주시면 됩니다. 예:

